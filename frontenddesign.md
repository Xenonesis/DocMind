# Minimal & Professional Design System

This design system replaces the previous "Brutalist & Terminal" style with a clean, modern, and professional aesthetic suitable for B2B SaaS or enterprise applications.

## 1. Typography
- **Primary Font**: `Bricolage Grotesque` or `Inter` (sans-serif) for headings and clean readability.
- **Secondary Font**: `Space Mono` only used sparingly for code blocks or data points, not for UI text.
- **Casing**: Use regular Sentence casing or Title Casing instead of ALL-CAPS uppercase strings.

## 2. Color Palette
- **Background**: Soft off-white for light mode (`#fafafa` or `hsl(0 0% 98%)`). Deep gray/black for dark mode (`#0a0a0a`).
- **Foreground**: Dark gray/slate for text in light mode, off-white for text in dark mode.
- **Primary**: A sophisticated brand color (e.g., modern blue or sleek solid black/white).
- **Borders**: Subtle and light, not thick black lines. (`hsl(var(--border))` with low opacity).

## 3. UI Components & Shapes
- **Borders & Radii**: Restore rounded corners (`radius: 0.5rem` or `0.75rem`) for cards, buttons, and inputs. Remove the 0px hard brute borders.
- **Shadows**: Use soft, diffused drop shadows (e.g., `box-shadow: 0 4px 14px 0 rgba(0,0,0,0.05)`) instead of hard, solid-color brutalist offset shadows.
- **Textures**: Remove the "paper/grit" radial gradient dot background. Use clean solid backgrounds or very subtle mesh gradients.

## 4. Copywriting and Terminology (Professionalism)
- **Buttons**: Replace commands like "INIT_LOGIN" or "INITIALIZE_SCAN" with "Log in", "Get Started", or "Upload Document".
- **Headings**: Replace aggressive, terminal-style wording ("EXTRACT ANALYZE DOMINATE") with value-driven SaaS copy ("Intelligent document processing and analysis.").
- **Navigation/Tabs**: Replace "CONTROL_PANEL", "SYS_CONFIG", "FILE_ARCHIVE" with standard terms like "Dashboard", "Settings", "Documents".

## 5. Layout and Spacing
- Maintain generous whitespace and padding (modern clean feel).
- Ensure components look lightweight and accessible rather than heavy and blocky.
